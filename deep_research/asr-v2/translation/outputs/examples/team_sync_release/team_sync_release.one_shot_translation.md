- Example: `team_sync_release`
- Variant: `one_shot_translation`
- Language Pair: `zh -> en`
- Segments: `3`

- [0000.00-0002.40] **SPEAKER_00**: Hello, let's start by reviewing the release status today.
- [0002.50-0004.80] **SPEAKER_01**: The payment issue was fixed yesterday.
- [0004.90-0007.00] **SPEAKER_00**: The dashboard design needs one more day.
